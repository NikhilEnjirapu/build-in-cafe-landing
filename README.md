# Build in Cafe — Landing Page

## Files
- `index.html` — complete landing page
- `style.css` — responsive visual system
- `script.js` — registration/WhatsApp links, countdown and reveal animation
- `assets/poster.jpg` — original supplied poster
- `assets/top-logos.jpg` — logo strip cropped directly from the supplied poster
- `assets/coffee-art.jpg` — coffee artwork cropped directly from the supplied poster
- `assets/partners.jpg` — partner strip cropped directly from the supplied poster

## Important: add the real links
Open `script.js` and replace:

```js
const REGISTRATION_URL = "https://your-registration-link.com";
const WHATSAPP_URL = "https://chat.whatsapp.com/YOUR_INVITE_CODE";
```

with the actual registration form and WhatsApp community URLs.

## Run locally
Just open `index.html` in a browser.

For deployment, upload the whole folder to Netlify, Vercel, GitHub Pages, or any static hosting provider.
"# build-in-cafe-landing"
